# Cybersecurity Fundamentals

## Authentication Methods

Multi-factor authentication (MFA) is a security method that requires users to provide two or more verification factors to gain access to a resource. The three main factors are:

1. **Something you know** - passwords, PINs, security questions
2. **Something you have** - smartphones, hardware tokens, smart cards  
3. **Something you are** - biometrics like fingerprints, facial recognition

## Common Attack Vectors

### Phishing Attacks
Phishing is a social engineering attack where attackers impersonate legitimate entities to steal sensitive information. Common indicators include:
- Suspicious sender addresses
- Urgent language and threats
- Requests for personal information
- Suspicious links and attachments

### SQL Injection
SQL injection occurs when malicious SQL code is inserted into application queries. Prevention methods include:
- Using parameterized queries
- Input validation and sanitization
- Principle of least privilege for database accounts
- Regular security testing

## Network Security

### Firewalls
Firewalls act as barriers between trusted internal networks and untrusted external networks. They can be:
- Hardware-based firewalls
- Software-based firewalls
- Next-generation firewalls (NGFW) with advanced features

### Encryption
Data encryption transforms readable data into an unreadable format using cryptographic algorithms. Modern encryption standards include:
- AES (Advanced Encryption Standard) for symmetric encryption
- RSA for asymmetric encryption
- TLS/SSL for secure communications

## Incident Response

A proper incident response plan includes:
1. **Preparation** - Establishing policies and procedures
2. **Detection and Analysis** - Identifying and assessing incidents
3. **Containment** - Limiting the scope and impact
4. **Eradication** - Removing the threat
5. **Recovery** - Restoring normal operations
6. **Lessons Learned** - Post-incident analysis and improvement
