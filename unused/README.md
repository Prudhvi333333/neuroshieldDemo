# Unused Files Directory

This directory contains test files and experimental code that were created during development but are not part of the core NeuroShield system.

## Test Files Moved Here:
- `test_*.py` - Various test scripts for Layer 2, Layer 3, async performance, and adversarial detection
- `debug_*.py` - Debug and diagnostic scripts
- Experimental implementations and performance benchmarks

## Core System Files (Active):
- `app.py` - Main Streamlit application
- `agents/` - Core agent implementations
- `api/` - FastAPI endpoints
- `utils/` - Classification utilities
- `langgraph_core/` - Orchestration logic

These files can be referenced for testing or debugging but are not required for production deployment.
